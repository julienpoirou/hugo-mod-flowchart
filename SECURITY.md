# Security policy

## Reporting a vulnerability
Please **do not** open a public issue.  
Contact: **julienpoirou@protonmail.com** (subject `[SECURITY]`).

We follow coordinated vulnerability disclosure. Please do not publicly disclose a vulnerability before a fix is available. We acknowledge reports within 72 hours, aim to provide a remediation timeline within 14 days, and coordinate the disclosure date with you, normally no later than 90 days after the initial report.

Include:
- module version, OS, Hugo version, browser if relevant
- reproduction steps
- estimated impact

We acknowledge within 72h and will work on a fix as soon as possible.

## Supported versions
- Latest release + previous (security patches).
